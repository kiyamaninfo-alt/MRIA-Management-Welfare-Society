# MRIA Management Welfare Society

Management Welfare Society information and administration system.

## Setup

1. Copy `.env.example` to `.env` and fill in your credentials:
   ```bash
   cp .env.example .env
   ```
2. Configure your Supabase project keys.

## Features (Planned)
- Member directory & resident profiles
- Property / Unit management
- Welfare fund & monthly contribution tracking
- Payment history & receipts
- Notices and announcements
